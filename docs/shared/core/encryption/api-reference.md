# Encryption API Reference

## Classes & Interfaces

### EncryptionService

- **Namespace:** `SmartWorkz.Shared.Security.Encryption.EncryptionService`
- **Summary:** AES-256 encryption service using CBC mode with PKCS7 padding.
            IV is prepended to ciphertext for decryption.

### IEncryptionService

- **Namespace:** `SmartWorkz.Shared.Security.Encryption.IEncryptionService`
- **Summary:** Service for encrypting and decrypting sensitive data using AES-256.

#### Methods & Properties

- **Encrypt** - Encrypts plaintext using AES-256 CBC mode with PKCS7 padding.
  - Parameters:
    - `plaintext`: The text to encrypt
    - `key`: 32-byte AES-256 key
  - Returns: Encrypted bytes (includes IV prepended)
- **Decrypt** - Decrypts ciphertext encrypted with Encrypt method.
  - Parameters:
    - `ciphertext`: Encrypted bytes (with IV prepended)
    - `key`: 32-byte AES-256 key used for encryption
  - Returns: Original plaintext
