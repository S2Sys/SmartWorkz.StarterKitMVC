# ServiceCRUDOperationsExample API Reference

## Classes & Interfaces

### OrderController

- **Namespace:** `SmartWorkz.Core.Examples.ServiceCRUDOperationsExample.OrderController`
- **Summary:** Demonstrates service usage in ASP.NET controller context.

#### Methods & Properties

- **CreateOrder** - POST /orders - Create order from DTO.
- **GetOrder** - GET /orders/{id} - Get order by ID.
- **UpdateOrder** - PUT /orders/{id} - Update order.
- **DeleteOrder** - DELETE /orders/{id} - Delete order.
- **GetAllOrders** - GET /orders - List all orders.
