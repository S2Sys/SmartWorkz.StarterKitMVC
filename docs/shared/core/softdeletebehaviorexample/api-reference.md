# SoftDeleteBehaviorExample API Reference

## Classes & Interfaces

### CustomerSpecification

- **Namespace:** `SmartWorkz.Core.Examples.SoftDeleteBehaviorExample.CustomerSpecification`
- **Summary:** Customer specification with soft delete filters.

#### Methods & Properties

- **WithActive** - Include only active (non-deleted) customers.
- **WithDeleted** - Include only soft-deleted customers.
- **DeletedSince** - Filter deleted customers within date range.

### SoftDeletePatterns

- **Namespace:** `SmartWorkz.Core.Examples.SoftDeleteBehaviorExample.SoftDeletePatterns`
- **Summary:** Soft delete workflow patterns.

#### Methods & Properties

- **Example_SoftDelete** - Example 1: Soft delete workflow.
- **Example_Restore** - Example 2: Restore soft-deleted entity.
- **Example_AutomaticFiltering** - Example 3: Automatic soft-delete filtering.
            Repositories automatically exclude soft-deleted by default.
- **Example_QueryDeleted** - Example 4: Query soft-deleted entities for audit/recovery.
- **Example_RecoveryWindow** - Example 5: Deleted within grace period (30 days).
- **Example_HardDelete** - Example 6: Hard delete after grace period.

### SoftDeleteAudit

- **Namespace:** `SmartWorkz.Core.Examples.SoftDeleteBehaviorExample.SoftDeleteAudit`
- **Summary:** Audit trail for soft deletes.

#### Methods & Properties

- **Example_AuditTrail** - Audit information captured on soft delete.
- **Example_Compliance** - Compliance: Prove data is trackable.

### SoftDeleteService

- **Namespace:** `SmartWorkz.Core.Examples.SoftDeleteBehaviorExample.SoftDeleteService`
- **Summary:** Service with soft delete support.

#### Methods & Properties

- **DeleteCustomer** - Service method: Delete customer (soft delete).
- **RecoverCustomer** - Service method: Recover deleted customer.
- **GetActiveCustomers** - Service method: List active customers (soft-deleted excluded).
