# TokenStorage API Reference

## Classes & Interfaces

### ISecureTokenStore

- **Namespace:** `SmartWorkz.Shared.Security.TokenStorage.ISecureTokenStore`
- **Summary:** Platform-agnostic secure token storage abstraction.
            Implementations use platform-specific secure vaults (Keychain, Android Keystore, Credential Manager).

#### Methods & Properties

- **SaveTokenAsync** - Stores a token securely in the platform vault.
  - Parameters:
    - `tokenKey`: Identifier for the token (e.g., "access_token", "refresh_token")
    - `token`: Token value to store
  - Returns: True if successfully stored, false otherwise
- **GetTokenAsync** - Retrieves a token from the platform vault.
  - Parameters:
    - `tokenKey`: Identifier for the token
  - Returns: Token value or null if not found
- **DeleteTokenAsync** - Removes a token from the platform vault.
  - Parameters:
    - `tokenKey`: Identifier for the token
  - Returns: True if successfully removed or not found, false if error
- **TokenExistsAsync** - Checks if a token exists in the vault.
  - Parameters:
    - `tokenKey`: Identifier for the token
  - Returns: True if token exists, false otherwise
- **ClearAllTokensAsync** - Removes all stored tokens.
  - Returns: True if successful, false otherwise
