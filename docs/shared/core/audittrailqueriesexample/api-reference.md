# AuditTrailQueriesExample API Reference

## Classes & Interfaces

### CustomerAuditSpecification

- **Namespace:** `SmartWorkz.Core.Examples.AuditTrailQueriesExample.CustomerAuditSpecification`
- **Summary:** Customer specification with audit filters.

### AuditTrailPatterns

- **Namespace:** `SmartWorkz.Core.Examples.AuditTrailQueriesExample.AuditTrailPatterns`
- **Summary:** Audit trail query patterns.

#### Methods & Properties

- **Example_RecentlyCreated** - Example 1: Find recently created entities.
- **Example_RecentlyModified** - Example 2: Find recently modified entities.
- **Example_CreatedByUser** - Example 3: Find entities created by specific user.
- **Example_Deleted** - Example 4: Find soft-deleted entities (recovery).
- **Example_RecentlyDeleted** - Example 5: Find recently deleted (recovery window).
- **Example_CountModified** - Example 6: Count modified in date range.

### AuditReporting

- **Namespace:** `SmartWorkz.Core.Examples.AuditTrailQueriesExample.AuditReporting`
- **Summary:** Audit trail reporting for compliance.

#### Methods & Properties

- **GenerateUserActivityReport** - Generate report: Changes by user (who changed what).
- **ComplianceReport.#ctor** - Generate compliance report: All changes in period.
- **RecoveryCandidate.#ctor** - Generate data recovery report: Recently deleted available for restore.

### AuditTrailService

- **Namespace:** `SmartWorkz.Core.Examples.AuditTrailQueriesExample.AuditTrailService`
- **Summary:** Service with audit trail support.

#### Methods & Properties

- **GetActivityLog** - Get activity log for audit purposes.
- **GetComplianceReport** - Get compliance report for period.
- **GetRecoveryCandidates** - Get recovery candidates for restore.

### AuditController
