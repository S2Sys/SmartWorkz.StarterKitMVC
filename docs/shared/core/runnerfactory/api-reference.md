# RunnerFactory API Reference

## Classes & Interfaces

### Runner

- **Namespace:** `System.Text.RegularExpressions.Generated.PlaceholderRegex_0.RunnerFactory.Runner`
- **Summary:** Provides the runner that contains the custom logic implementing the specified regular expression.

#### Methods & Properties

- **Scan** - Scan the  starting from base.runtextstart for the next match.
  - Parameters:
    - `inputSpan`: The text being scanned by the regular expression.
- **TryFindNextPossibleStartingPosition** - Search  starting from base.runtextpos for the next location a match could possibly start.
  - Parameters:
    - `inputSpan`: The text being scanned by the regular expression.
  - Returns: true if a possible match was found; false if no more matches are possible.
- **TryMatchAtCurrentPosition** - Determine whether  at base.runtextpos is a match for the regular expression.
  - Parameters:
    - `inputSpan`: The text being scanned by the regular expression.
  - Returns: true if the regular expression matches at the current position; otherwise, false.
