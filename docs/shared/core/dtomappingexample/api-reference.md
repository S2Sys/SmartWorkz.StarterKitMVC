# DTOMappingExample API Reference

## Classes & Interfaces

### DTOMappingPatterns

- **Namespace:** `SmartWorkz.Core.Examples.DTOMappingExample.DTOMappingPatterns`
- **Summary:** DTO mapping patterns in service layer.

#### Methods & Properties

- **MapToDto** - Example 1: Entity to DTO mapping (for Read operations).
- **MapToEntity** - Example 2: DTO to Entity mapping (for Create operations).
- **MapToDto** - Example 3: Batch mapping (collection).
- **CustomerPublicDto.#ctor** - Example 4: Selective field exposure (security).
- **Example_FlatteningValueObjects** - Example 5: Flattening nested value objects.

### CustomerService

- **Namespace:** `SmartWorkz.Core.Examples.DTOMappingExample.CustomerService`
- **Summary:** Service layer with DTO mapping.

#### Methods & Properties

- **CreateCustomer** - CREATE: DTO -> Entity -> Persist -> DTO
- **GetCustomer** - READ: Entity -> DTO
- **UpdateCustomer** - UPDATE: DTO -> Update Entity -> Persist -> DTO
- **GetAllCustomers** - LIST: Entities -> DTOs

### CustomerController

- **Namespace:** `SmartWorkz.Core.Examples.DTOMappingExample.CustomerController`
- **Summary:** ASP.NET controller using DTOs.

#### Methods & Properties

- **CreateCustomer** - POST /customers - Create from DTO
- **GetCustomer** - GET /customers/{id} - Return as DTO
- **UpdateCustomer** - PUT /customers/{id} - Update from DTO
- **GetAllCustomers** - GET /customers - Return as DTOs
