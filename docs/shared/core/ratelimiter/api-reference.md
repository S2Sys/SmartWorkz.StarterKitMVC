# RateLimiter API Reference

## Classes & Interfaces

### TokenBucket

- **Namespace:** `SmartWorkz.Shared.RateLimiter.TokenBucket`
- **Summary:** Internal token bucket implementation with thread-safe token refill calculation.

#### Methods & Properties

- **TryAcquire** - Tries to acquire the specified number of tokens.
- **GetAvailableTokens** - Gets the current number of available tokens.
- **GetRetryAfterMilliseconds** - Gets the number of milliseconds to wait before retrying.
- **RefillTokens** - Refills the token bucket based on elapsed time.
