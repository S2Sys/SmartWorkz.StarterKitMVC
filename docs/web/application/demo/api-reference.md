# Demo API Reference

## Classes & Interfaces

### TranslationsModel

- **Namespace:** `SmartWorkz.StarterKitMVC.Public.Pages.Demo.TranslationsModel`
- **Summary:** Demo page showing all translation keys and their current values.
            Demonstrates the translation system for developers.

### ValidationModel

- **Namespace:** `SmartWorkz.StarterKitMVC.Public.Pages.Demo.ValidationModel`
- **Summary:** Demo page showcasing the simple validation approach using MessageKey error messages.
            Demonstrates required, email, string length, format, and custom validation.
