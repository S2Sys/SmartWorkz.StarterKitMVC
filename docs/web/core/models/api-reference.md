# Models API Reference

## Classes & Interfaces

### FormDefinition

- **Namespace:** `SmartWorkz.Web.Models.FormDefinition`
- **Summary:** Represents the complete definition of a dynamic form

### FormField

- **Namespace:** `SmartWorkz.Web.Models.FormField`
- **Summary:** Represents a single field in a form

### FormFieldOption

- **Namespace:** `SmartWorkz.Web.Models.FormFieldOption`
- **Summary:** Represents an option in a select or dropdown field

### FormValidationRule

- **Namespace:** `SmartWorkz.Web.Models.FormValidationRule`
- **Summary:** Represents a validation rule for a form field

### FormSubmitConfig

- **Namespace:** `SmartWorkz.Web.Models.FormSubmitConfig`
- **Summary:** Configuration for form submission

### FormSubmissionResult

- **Namespace:** `SmartWorkz.Web.Models.FormSubmissionResult`
- **Summary:** Result returned after form submission

### FormValidationError

- **Namespace:** `SmartWorkz.Web.Models.FormValidationError`
